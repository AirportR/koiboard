# 设计系统

## 气质

深色为默认：近黑画布、低对比网格、玻璃质感的面板、单一薄荷强调色。浅色主题保持同一层级关系，仅替换令牌。

## 颜色令牌

| 令牌 | 深色 | 用途 |
| --- | --- | --- |
| `--bg` | `#07090c` | 画布 |
| `--surface` | `#0e1319` | 面板 |
| `--surface-2` | `#121821` | 输入 / 次级按钮 |
| `--surface-3` | `#17202a` | 悬浮 / 选中 |
| `--line` | `rgba(255,255,255,.07)` | 分隔线 |
| `--text` / `--text-2` / `--text-3` | `#e8eef3` / `#9aa8b6` / `#6a7887` | 三级文字 |
| `--mint` | `#6ef3c5` | 主强调、成功、可交互 |
| `--iris` | `#9f8cff` | 信息、演示、只读 |
| `--amber` | `#ffc46b` | 未保存、风险 |
| `--coral` | `#ff7a85` | 错误、失效 |

浅色主题对应 `#f2f5f4` / `#ffffff` / `#0b9c76`，文字三级 `#5c6d68` 以满足正文对比度。

## 字体与字号

- `--font-sans`：Inter 优先，回退到系统 UI 与中文字体
- `--font-mono`：JetBrains Mono / Cascadia Code，用于路径、数值、标识
- 标题 `clamp(28px, 3.3vw, 40px)`，字重 600，字距 -0.035em
- 正文 15px / 1.55；字段标签 12px；提示 11.5px；元信息 9.5–10.5px（mono + 大写 + 字距）

## 间距与圆角

- 间距序列：4 / 8 / 12 / 14 / 18 / 22 / 26
- 圆角：9 / 12 / 18 / 22（小控件 / 输入 / 面板 / 弹层）
- 触控目标：桌面 36px，移动端 ≥40px，行高 ≥60px

## 组件

- **Panel**：面板头 + 内容 + 可选脚注；头部含微标签（eyebrow）、图标块与右侧动作
- **Row**：索引徽标 + 标题/副标题 + 徽章 + 操作 + 折叠箭头；展开用 `grid-template-rows: 0fr → 1fr`
- **Field**：标签（含未保存圆点与「详情」）+ 控件 + 提示；开关字段独立成横向卡片
- **Dock**：固定底部，展示改动数量、阶段、撤销重做、还原、校验、保存、重载
- **Palette**：⌘K 搜索，分组「未保存改动 / 跳转视图 / 配置字段 / 操作」
- **Drawer**：字段详情，含路径、类型、说明、当前值、运行态值、风险与还原

## 动效

| 场景 | 时长 / 曲线 |
| --- | --- |
| 视图进入 | 340ms `cubic-bezier(.16,1,.3,1)`，8px 位移 |
| 行展开 | 300ms `grid-template-rows` |
| 面板 / 卡片悬浮 | 140–200ms |
| 抽屉 / 弹层 | 260–300ms |
| 连接灯 | 2.4s 呼吸环 |

全部动效在 `prefers-reduced-motion: reduce` 下退化为即时状态。

## 响应式

| 断点 | 变化 |
| --- | --- |
| ≤1120px | 内容收窄，双栏变单栏 |
| ≤900px | 隐藏左侧轨道，出现移动标签栏 + 全屏导航；草稿坞上移 |
| ≤720px | 顶栏精简，行改为两行布局，操作按钮悬浮右上 |
| ≤620px | 隐藏非主操作顶栏按钮与连接状态，提示文本换行 |
| ≤560px | 统计卡两列，色卡行折行 |

移动端习惯：底部标签栏常驻、全屏导航分组、草稿坞与标签栏叠放、搜索按钮独立可点、敏感/危险操作保留在抽屉与命令面板。
